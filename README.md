# Retail Sales Analysis

## Project Overview
This project focuses on analyzing retail sales data using Python to understand sales performance, product category revenue, and customer purchasing patterns.

## Objectives
- Analyze retail sales data.
- Check missing values and duplicate records.
- Calculate total revenue and average transaction amount.
- Identify the highest-revenue product category.
- Analyze monthly sales trends.
- Create visualizations and derive business insights.

## Dataset
The dataset contains 1,000 transactions and 9 columns:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Work Performed
1. Inspected the dataset and checked data types.
2. Checked missing values and duplicate records.
3. Converted the Date column into a datetime format.
4. Calculated total revenue, average transaction amount, and total products sold.
5. Analyzed revenue by product category and gender.
6. Compared average transaction amounts across product categories.
7. Analyzed monthly sales trends.
8. Created bar charts and a line chart for visualization.

## Key Business Insights
- Total revenue was 456,000 across 1,000 transactions.
- The average transaction amount was 456.
- A total of 2,514 products were sold.
- Electronics generated the highest revenue of 156,905.
- Female customers generated 232,840 in revenue, compared with 223,160 from male customers.
- Beauty had the highest average transaction amount, approximately 467.48.

## Conclusion
This project demonstrates the use of Python for data cleaning, exploratory data analysis, data visualization, and extracting meaningful business insights from retail sales data.
